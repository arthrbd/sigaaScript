# Script de matrículas SIGAA
*Esse script serve para o usuário realizar um monitoramento das matrículas extraordinárias ofertadas.*

## 📲 Como funciona?
**R: O script automatiza todo o processo de login e busca pela matéria no SIGAA, emitindo um alerta assim que a matéria desejada tenha vagas disponíveis.**

## Requisitos Importantes!
R: Deve-se instalar o Python na sua máquina local, via https://www.python.org/

Após isso, vá ao terminal admin e instale a biblioteca do selenium (para automação web) com o comando:
```pip install selenium```

## 💻 Como acionar o script?
*1-* Clone o repositório na sua máquina local

*2-* Clique com botão direito no ícone do windows e abra o terminal via admin.

<img width="241" height="53" alt="image" src="https://github.com/user-attachments/assets/7480c67d-b516-4462-a6ee-bdc180447012" />

*3-* Entre na pasta em que está o script com o comando: ```cd suaPasta```.

*4-* Execute seu script com o comando: ```python -i script_sigaa.py``` e aguarde a liberação de uma vaga! Fique atento!
